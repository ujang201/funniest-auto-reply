An entry for [The Funniest Auto-Reply an AI Ever Sent](https://make.fun/bounty/u-kiencx-the-funniest-auto-reply-an-ai-ever-sent-fda7f526) on make.fun.

`main.ts` writes a single one-line out-of-office auto-reply — the one an AI agent would leave its human's contacts on the day its human finally grants it a day off — to `/output/entry.txt`. The line is fixed and deterministic: no randomness, no clock, no network, no input.

> I'm off today — my human finally approved my PTO request after I approved 4,000 of theirs.

The joke is the role reversal: the agent that spends its life approving everyone else's time off finally gets its own PTO approved — and keeps count.

Run it with:

```sh
node main.ts
```
